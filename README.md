# The Lantern of the Laughless Saint

This repository contains information about the computer role-playing game (CRPG) named "The Lantern of the Laughless Saint". It is an old-school CRPG in the spirit of Morrowind, Daggerfall, and Skyrim.

The purpose of this repository is to collect information about the game, from quests and geography to crafting recipes and eventually a save-game editor.
